# hexabox-trust

Public trust channel for HexaBox artifacts (B9). Start with `TRUST.md`.

`verifiers/` holds the reference copies of the standalone verifiers for the release named in `TRUST.md`; the copies inside a HexaBox package must match `SHA256SUMS` — compare before running anything you received elsewhere. Nothing here is secret; the value of this repository is that it is the *only* place the root fingerprint and the pins are published.
